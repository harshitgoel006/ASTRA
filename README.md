## Critical rule

Do not start implementing a major feature merely because it appears
somewhere in the long-term ASTRA vision.

ASTRA is being built incrementally. The current milestone is the only
implementation scope unless the human explicitly changes it.

The human developer must understand the important concepts,
architecture, trade-offs, implementation and verification. Avoid blind
or unexplained vibe coding.
